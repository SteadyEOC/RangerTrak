Set up the RangerTrak Board

The Board lets everyone at the command post watch the live radio log on their own phone, tablet or laptop. It runs on one computer at the command post, and needs no Internet once it is set up. Tick each step as you go.

Steps for:

Before you go (needs the Internet, once)

1. Install Node.js

The Board runs on Node.js, a free program. You need version 24 or newer.

Download Node.js (LTS)

No extra tools are needed. Accept the installer's defaults.

Run the .msi installer. When it offers Automatically install the necessary tools (Chocolatey, Python, build tools), leave that box unchecked.

Run the .pkg installer.

Use your distribution's package manager or the instructions on nodejs.org. Check with node --version: it must print v24 or higher.

2. Download the Board kit

On the newest release, under Assets, download rangertrak-board-<version>.zip (not the web zip).

Newest release

3. Unzip it

Put it in a folder you can find again, such as Documents\RangerTrak Board. Don't run it from inside the zip.

Right-click the zip, Extract All, then Extract.

Double-click the zip.

unzip rangertrak-board-*.zip -d "RangerTrak Board"

4. Install RangerTrak on the scribe's device

Open rangertrak.org on the device the scribe logs on, and install it (the browser's Install button) so it works offline. It can be the same computer as the Board.

At the command post

5. Join the Wi-Fi and start the Board

Join the Wi-Fi or hotspot everyone will use. Plug the computer in and keep the lid open: if it sleeps, the Board stops.

Double-click Start RangerTrak Board.bat.

  • "Windows protected your PC"? Click More info, then Run anyway.
  • Asked whether to allow Node.js on private networks? Click Allow.

The first time, right-click (or Control-click) Start RangerTrak Board.command, choose Open, then Open. After that, double-click it.

In a terminal, in the kit's folder: node rangertrak-board.js. Linux reserves port 443, so the Board may move to another port. Use exactly the address it prints.

A window opens with two steps in it. Keep it open; closing it stops the Board.

6. Connect the scribe's RangerTrak

Use the address in the window's STEP 1, normally https://rangertrak-board.local. It is already copied on the Board computer.

  1. Open that address once in the scribe's browser. It warns Your connection is not private: expected for a private server. Click Advanced, then Proceed.
  2. In RangerTrak: Mission page, RangerTrak Board card. Turn on Send this log to a RangerTrak Board, paste the address, and press Test connection.
  3. Chrome or Edge may ask: rangertrak.org wants to access other devices on your local network. Click Allow. That is how RangerTrak reaches the Board.

Use that address even when RangerTrak runs on the Board computer itself, not localhost.

7. Let viewers in

Viewers open the address in the window's STEP 2 (the same address with /view on the end), or scan the QR code. They install nothing. The first time, each device shows the same warning: Advanced, then Proceed.

The roster never goes to the Board, only report content.

Something not working?
Test connection says the certificate isn't accepted
Open the Board's address in that device's browser, choose Advanced, then Proceed, and test again. A Board that isn't running looks the same, so check its window too.
Test connection says the browser is blocking the local network
Block was clicked on the local network question. Click the icon at the left of the address bar, open Site settings, set Local network access to Allow, reload, and test again.
Nothing answers
The device is probably on a different Wi-Fi from the Board computer. A VPN or web-protection app can also be in the way; turn it off while you use the Board.
The name doesn't open (often older Android phones)
Use the numbered address printed under it, such as https://10.0.0.15/view.
Windows treats the Wi-Fi as Public
Windows then blocks other devices. The Board's window says so and offers the fix.
Hotel or public Wi-Fi
Many keep devices apart. Use your own router or a phone hotspot.
A phone says "No internet" on the Wi-Fi
Choose Stay connected, or it may switch to mobile data and lose the Board.
Two Boards on one network
The second calls itself rangertrak-board-2.local. Use the address its own window prints.

More in RangerTrak's Help (the Board's entry on the Mission page) and the FAQ. Still stuck? Tell us on GitHub.
