RangerView mini web server
==========================

RangerView is a remote view of the radio log: it lets people on the command post's Wi-Fi or hotspot
watch the live log on their own phone, tablet or laptop. This kit holds its mini web server. It runs on one laptop or desktop at the command post. That can be
the same computer the scribe logs on.

Nothing here touches the Internet once it is set up, and nothing is saved to disk except the
RangerView's own certificate (in the certificate folder), unless you turn on the log (see below).


WHICH COMPUTERS
---------------
The mini web server runs on Windows 10 or 11, macOS, or Linux. Viewers can use any phone, tablet or
computer with a web browser; they install nothing.


The same steps, with a checklist: https://rangertrak.org/view/


BEFORE YOU GO (needs the Internet, once)
----------------------------------------
1. Install Node.js, the LTS version (24 or newer), from https://nodejs.org/en/download
   No extra tools are needed. Accept the installer's defaults, and leave "Automatically install
   the necessary tools" (Chocolatey, Python, build tools) UNCHECKED.
     Windows: run the .msi installer.
     Mac:     run the .pkg installer.
     Linux:   use your distribution's package manager or the nodejs.org instructions. Check
              with "node --version": it must print v24 or higher.
2. Unzip this whole kit into a folder you can find again, for example Documents\RangerView.
   Don't run it from inside the zip.
     Windows: right-click the zip, Extract All, Extract.
     Mac:     double-click the zip.
     Linux:   unzip rangerview-*.zip -d "RangerView"


AT THE COMMAND POST
-------------------
1. Join the Wi-Fi or hotspot everyone will use.
2. Start the mini web server:
     Windows: double-click "Start RangerView.bat".
              If a blue "Windows protected your PC" box appears, click More info, then Run anyway.
              If Windows asks whether to allow Node.js on private networks, click Allow.
     Mac:     the first time, right-click (or Control-click) "Start RangerView.command",
              choose Open, then Open. After that, double-click it.
     Linux:   in a terminal, in the kit's folder:  node rangerview.js
              The mini web server uses port 443, which Linux reserves; if it says so, it moves to another
              port and prints the address with that port. Use exactly what it prints.
3. A window opens. STEP 1 in it is the address for the scribe: the name, normally
   https://rangerview.local (already copied on that computer), and a numbered one under
   it such as https://10.0.0.15. If the name doesn't work on another device, use the numbered
   one. Keep the window open;
   closing it stops the mini web server.
4. On the scribe's device, open that address in the browser once. It warns "Your connection is
   not private". That is expected for a private server: click Advanced, then Proceed. Once per
   device; viewers do the same the first time.
5. In RangerTrak, open Mission > RangerView, paste the address into Server address, and
   press Test connection. When it says Connected, turn on "Send this log to a remote view (RangerView)".
   Use that address even on this same computer, not "localhost": the viewer link is made from it.
   Chrome or Edge may ask "rangertrak.org wants to access other devices on your local
   network". Click Allow: that is how RangerTrak reaches the mini web server.
6. STEP 2 in the window is for viewers: the same address with /view on the end, or the QR code.


THE LOG
-------
The mini web server keeps no log unless you ask for one. If something isn't working and someone is helping
you, start it from a terminal with:  node rangerview.js --log
Each run then writes a new file in the logs folder, named for the date and time, for example
logsoard-2026-11-14-110509.txt. It holds everything the window shows, plus one line for each
connection: the time, the device's address, what it asked for and how long it took. It never
holds the passwords or keys devices send. Send that file to whoever is helping you.


GOOD TO KNOW
------------
- The roster never goes to RangerView, only report content.
- Some guest Wi-Fi (hotels, public hotspots) stops devices reaching each other. Use your own
  router or a phone hotspot.
- To install RangerTrak itself on a device for offline use, open https://rangertrak.org on it
  while you still have the Internet. The mini web server is for watching the log, not for installing the app.
- Help, in RangerTrak, has more: the mini web server's entry in the Mission page's Help, and the FAQ.
