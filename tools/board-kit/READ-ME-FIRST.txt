RangerTrak Board
================

The Board lets people on the command post's Wi-Fi or hotspot watch the live radio log on their
own phone, tablet or laptop. It runs on one laptop or desktop at the command post. That can be
the same computer the scribe logs on.

Nothing here touches the Internet once it is set up, and nothing is saved to disk except the
Board's own certificate (in the certificate folder).


WHICH COMPUTERS
---------------
The Board runs on Windows 10 or 11, macOS, or Linux. Viewers can use any phone, tablet or
computer with a web browser; they install nothing.


The same steps, with a checklist: https://rangertrak.org/board/


BEFORE YOU GO (needs the Internet, once)
----------------------------------------
1. Install Node.js, the LTS version (24 or newer), from https://nodejs.org/en/download
   No extra tools are needed. Accept the installer's defaults, and leave "Automatically install
   the necessary tools" (Chocolatey, Python, build tools) UNCHECKED.
     Windows: run the .msi installer.
     Mac:     run the .pkg installer.
     Linux:   use your distribution's package manager or the nodejs.org instructions. Check
              with "node --version": it must print v24 or higher.
2. Unzip this whole kit into a folder you can find again, for example Documents\RangerTrak Board.
   Don't run it from inside the zip.
     Windows: right-click the zip, Extract All, Extract.
     Mac:     double-click the zip.
     Linux:   unzip rangertrak-board-*.zip -d "RangerTrak Board"


AT THE COMMAND POST
-------------------
1. Join the Wi-Fi or hotspot everyone will use.
2. Start the Board:
     Windows: double-click "Start RangerTrak Board.bat".
              If a blue "Windows protected your PC" box appears, click More info, then Run anyway.
              If Windows asks whether to allow Node.js on private networks, click Allow.
     Mac:     the first time, right-click (or Control-click) "Start RangerTrak Board.command",
              choose Open, then Open. After that, double-click it.
     Linux:   in a terminal, in the kit's folder:  node rangertrak-board.js
              The Board uses port 443, which Linux reserves; if it says so, it moves to another
              port and prints the address with that port. Use exactly what it prints.
3. A window opens. STEP 1 in it is the address for the scribe, normally
   https://rangertrak-board.local (already copied on that computer). Keep the window open;
   closing it stops the Board.
4. On the scribe's device, open that address in the browser once. It warns "Your connection is
   not private". That is expected for a private server: click Advanced, then Proceed. Once per
   device; viewers do the same the first time.
5. In RangerTrak, open Mission > RangerTrak Board, turn on "Send this log to a RangerTrak Board",
   paste the address, and press Test connection. Use that address even on this same computer,
   not "localhost": the viewer link is made from it.
   Chrome or Edge may ask "rangertrak.org wants to access other devices on your local
   network". Click Allow: that is how RangerTrak reaches the Board.
6. STEP 2 in the window is for viewers: the same address with /view on the end, or the QR code.


GOOD TO KNOW
------------
- The roster never goes to the Board, only report content.
- Some guest Wi-Fi (hotels, public hotspots) stops devices reaching each other. Use your own
  router or a phone hotspot.
- To install RangerTrak itself on a device for offline use, open https://rangertrak.org on it
  while you still have the Internet. The Board is for watching the log, not for installing the app.
- Help, in RangerTrak, has more: the Board's entry in the Mission page's Help, and the FAQ.
