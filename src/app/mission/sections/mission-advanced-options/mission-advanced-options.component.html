Mission backup

Backs up this device’s entire mission — settings, rangers and field reports — to a single file, so it survives clearing browser storage or a move to another device.

The backup file includes the ranger roster — legal names, personal phone numbers and call signs. Backing up offers an optional passphrase: type one and the file is encrypted, leave it blank and it is not. Either way, store it carefully and delete it when the mission is over.

warning Danger zone

Each of these replaces or discards data already on this device, and cannot be undone. Back up your mission first if you need to keep it.
