Especially on iPhone and iPad: every browser there, Chrome included, runs on Safari’s engine, which does not reliably honor this protection and can clear a site’s data after about a week unused. Safari on a Mac does the same. There, installing RangerTrak and backing up your mission are the real protection.

Mission backup

Backs up this device’s entire mission — settings, rangers and radio log entries — to a single file, so it survives clearing browser storage or a move to another device. Ranger photos are included.

The backup file includes the ranger roster — legal names, personal phone numbers and call signs. Backing up offers an optional passphrase: type one and the file is encrypted, leave it blank and it is not. Either way, store it carefully and delete it when the mission is over.

Field phone

Makes this device a ranger’s own field phone: only Radio Log Entry and Help stay on the menu, and Send my reports passes reports to the command post. Meant for phones and tablets; the welcome panel offers it there.

It hides this Mission page, so it is only offered on a brand-new device: no rangers, no radio log entries and no mission name. To turn it off again, use Turn off field mode in Help.
