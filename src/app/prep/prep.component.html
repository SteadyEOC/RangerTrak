Export setup files

Packages whichever categories are checked below - THIS device's current roster (with ranger photos), locations, and/or mission settings - into one downloadable .zip. Uncheck a category to build a narrower file, e.g. a Rangers-only file for one team. Deliberately never includes field reports - a setup file is a pre-mission provisioning artifact, not a mid/post-mission backup (use the Mission page's own "Back up mission" for that).

Rangers (with photos) Locations Mission settings
Confidential: a setup file carrying Rangers contains real names, phone numbers and photographs of volunteers. Do not email it, do not put it in source control, and wipe the drive it's on after the mission.
Import setup files

Loads one or more setup files someone handed you. Each file's rangers and locations merge into what is already on this device - a row that matches an existing one (by id, or by name for a location) is updated in place, everything else already here is kept. Mission settings, when a file carries them, are applied wholesale. Field reports already on this device are never touched - a setup file has none of its own to bring in.

Picking several files at once applies them in FILENAME order - name them 01-rangers-teamA…, 02-locations… to control which one wins when two files touch the same row.
