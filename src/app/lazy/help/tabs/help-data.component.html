Where your data is

In this browser, on this device. Not on a server, not in an account, not shared with the other devices your team is using. Each browser on each device keeps its own separate copy.

That is what lets RangerTrak work with no connection. It also means the device is the only copy, so back it up.

The roster is confidential

The roster holds legal names, personal phone numbers, and call signs that tie each row to a publicly searchable license record. It is stored unencrypted on the device. Rangers' own Export roster, and every spreadsheet export, are plain-text files too. Mission's Back up mission is the one exception: it includes the roster, and it now offers an optional passphrase - leave it blank and it's the same plain file as before, type one and the file is encrypted. Share exports only with people who need them for this mission, and delete them when the mission is over.

Given a callsign, the FCC's own public licensee lookup already shows more than this roster does - legal name and mailing address for any licensed amateur radio operator. This app does not meaningfully add to that public exposure, with one exception: photographs, which are not part of any public record.

Getting data off the device

Mission's Back up mission is the one to reach for by default — it round-trips everything (settings, roster and reports) back in on another device, so it doubles as the actual backup. Rangers's Export roster moves just the roster, the same round-trip way. The Setup files page is different from both: it packages any combination of roster, photos, locations and settings — but never field reports — for setting up a NEW device before a mission starts, merging into whatever is already there rather than replacing it, which none of the others do (Export roster never includes photos or merges; Back up mission is a mid/post-mission backup that assumes reports already exist and always replaces wholesale). Export on Radio Log or Rangers instead produces an Excel-friendly spreadsheet — useful for working with the data, but one-way: it cannot be imported back in.

Ranger photographs stay on the device they were added to. They are never uploaded. Name each file after the ranger's id or callsign - any common image format works.

Starting a device over

See the After mission tab for what to export, clear or reset once an operational period ends.

Reporting a problem

The Log page records what the app did this session. On the Feedback tab, press Copy log to clipboard and paste it into the message field — it is far more useful than a description of what went wrong.

The log is cleared when you reload, so copy or export it before reloading. It is a raw diagnostic record and can contain report details, addresses and call signs, so treat it as confidential.

There is a feedback form on the Feedback tab. Anything sent through it becomes a public issue on the project's repository, so keep mission data out of it.
