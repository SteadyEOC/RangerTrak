Get set up

  1. Set up your mission. Open Mission and set the mission name, the operational period, and a default latitude/longitude near your operating area — new reports start from there, which saves typing on every single one.
    Mission settings are not saved until you press Save. Unlike the Radio Log and Rangers grids, which save edits themselves, this page waits for you.
  2. Load your roster. Open Rangers and import or add your team.
  3. Go to Field Entry. Click the RangerTrak name in the header to get there (it is also the home page). That is where you will spend the incident.

The colored dot in the page header tracks those three steps. Hover it for what is still missing; click it to jump to Mission.

Do this before you need it. RangerTrak works with no Internet — but only once it has loaded at least once on this device. A device that has never opened RangerTrak and has no connection gets nothing. Install it, and open the map for your area, while you still have a signal.

Most of the rest of the Mission page has a sensible default and can be left alone. These are the ones worth knowing about, because their effect shows up somewhere else.

Coordinates and Plus Codes are calculated on your device, so they keep working when nothing else does. Addresses have to be looked up. See Maps for saving map coverage ahead of time.

A device is set up one of two ways. The full app is for the command post scribe: every page, the roster, the maps and the mission settings. Field mode is for a ranger's own phone, to file their own reports. It shows only Entry and Help - AAR (after-action review) notes have no menu item on either device, but the AAR note button at the top of the page still works in field mode, and its dialog's See all notes link reaches the notes page from there too. On a brand-new phone or tablet the welcome panel offers field mode; on a laptop it is under Mission > Advanced > Field phone. Either way it is only offered on a brand-new device, and it cannot be turned off again from inside the app.

RangerTrak never sends a report over the network by itself. Every report is saved on the phone the moment it is submitted, with or without a signal. Sending is a separate step:

  1. On the phone, Send my reports (above the Entry form) puts every report on the phone into one small file and opens the phone's share sheet.
  2. The ranger picks the route: email or a messaging app over cell data or WiFi, or AirDrop / Nearby Share to a station device close by. With no signal, send it later. Nothing is lost by waiting.
  3. At the command post, Load Report Packet on the Radio Log page merges the file in. Reports already in the log are skipped, so sending the same file twice does no harm.

No data at all? Read the report over the radio and the scribe types it in, as always. That is also the right choice for anything urgent or needing a reply: the phone's Online/Offline badge only says the phone has some connection, not that a report arrived, and the phone gets no receipt when it is merged.

Install first. Install RangerTrak on the phone from rangertrak.org before heading out. That one visit needs the Internet; after it, entering reports works offline.

RangerTrak Board is not a third kind of device. It is an optional extra on the command post's full app (Mission page): the station publishes a read-only copy of the log, without the roster, to the RangerTrak Board program on a laptop on its own WiFi or hotspot, so people on that network can watch it in a browser. Reports still only go into the log at the command post; phones cannot send reports through it.

At the bottom of the Mission page, the Data safety card holds:

  • Request persistent storage — ask the browser not to discard your mission when it is short of space. Accept if offered. On iPhone and iPad (every browser) and in Safari on a Mac this is not reliable, and data can be cleared after about a week unused — install RangerTrak and back up.
  • Back up mission — the whole mission as one file, for backup or handover to another device. It offers an optional passphrase that encrypts the file.

Below it, the collapsed Danger zone holds:

  • Reset mission to defaults — back to defaults, at the start of a new incident.
  • Restore mission — load a file made by Back up mission.
  • Load sample mission — a ready-made demonstration mission, for training or showing someone the app. Pick one from Demo scenario first. On a brand-new device, Field Entry's welcome panel offers the same thing as Load Demo Data.
Load sample mission, Restore mission and Reset mission to defaults all replace what is on this device. Back up first if you need to keep it.

On iPhone or iPad: an installed RangerTrak (added to the Home Screen) keeps its own storage, separate from Safari's. If you set up a mission in a Safari tab first, it will not appear once you install the app. Install RangerTrak before setting up a mission — or if you already set up in Safari, use Back up mission there, then Restore mission in the installed app.
