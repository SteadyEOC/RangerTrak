Report a problem or suggest something

RangerTrak is a free, open-source project from SteadyEOC (rangertrak.com). Use the form below, or visit the project on GitHub directly, or email RangerTrak@steadyeoc.com. Not all feedback needs to become an issue - if you're unsure, describe what you saw and let the maintainer sort it.

Feedback or an AAR note? Feedback goes to RangerTrak's developers right away, as a public GitHub issue, and needs a connection. An AAR note (the button at the top of every page) stays private on this device for your own team's after-action review. It works offline and is part of the mission backup. In the field with no signal, or no time? Press AAR note and mark it RangerTrak. Later, Review and send on the AAR notes page brings those notes here, for you to check before anything is sent.

RangerTrak is free and will stay free. If it's useful to your team, you can support its development at buymeacoffee.com/JohnCornelison. That goes to the developer personally and isn't tax-deductible. Feedback helps just as much.

RangerTrak keeps a running record of what it did this session - useful when something goes wrong and you want to report it, or figure out why.

Open the Log page

There is no menu entry for it on purpose - it is a diagnostic tool, not something you need during normal use. This section exists so it is still easy to find when you do need it.

On the Log page, press Copy log to clipboard, then paste it into the message field above (or into a GitHub issue). It is far more useful to a diagnosis than a description of what went wrong.
