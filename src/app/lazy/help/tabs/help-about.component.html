What RangerTrak is

A log of who is where, when, and in what condition, for teams reachable only by voice radio. Field teams radio in; you transcribe; RangerTrak maps it and keeps the record.

It runs entirely in this browser, on this device. No server, no account, no login. Your mission stays on this device. When online, the app fetches map images and looks up addresses for report locations. See RangerTrak's privacy policy for the full picture.

Two phases, even when one person does both

Setup is infrequent and considered — Mission and Rangers, before or between operational periods. Entry is repetitive and time-critical — the entry screen, while reports come in. The app is built around the second one being fast.

RangerTrak is made by SteadyEOC: one person building tools for emergency teams that have to keep working when the network doesn't. RangerTrak is free and open source (AGPL), so any team can run it, adapt it, and keep using it for as long as they need. There's no licence to renew and no vendor to outlive. More at rangertrak.com.

To report a problem or suggest something, see the Feedback tab.

  • A Progressive Web App: installable, and runs with no Internet once loaded
  • Angular 22 with TypeScript, signals, zoneless change detection, and Material Design
  • Leaflet maps with marker clustering, an overview map, and offline tile saving
  • MapLibre GL + PMTiles: a vector map with basemap data bundled into the app
  • Address lookup via OpenStreetMap's Nominatim by default, with no API key - an optional Google Geocoding key can be supplied instead on the Mission page's Maps card
  • Plus Codes and all lat/long conversion computed on-device
  • AG Grid tables with searching, sorting, filtering and export
  • No cookies, no accounts, no server: data stays in your browser's local storage
  • Angular and Angular Material — the framework and the components almost everything on screen is built from
  • AG Grid (Community edition) — the Rangers, Reports and Messages tables
  • Leaflet, plus leaflet.offline — the Leaflet map engine and its offline tile saving
  • MapLibre GL JS and PMTiles / Protomaps — the vector map engine and its bundled offline basemap format
  • © OpenStreetMap contributors — the map data underneath both map engines
  • OpenTopoMap (CC-BY-SA) — the topographic map style
  • Esri — the hillshade (terrain relief) layer and the satellite imagery base map
  • Waymarked Trails (© waymarkedtrails.org, data © OpenStreetMap contributors, CC-BY-SA) — the hiking trails overlay
  • Nominatim, OpenStreetMap's own geocoder — the default address lookup, no API key needed
  • pdf-lib — fills the printable ICS-213 and ICS-309 forms
  • fflate — the zip work behind mission backup/restore and bulk photo import
  • SheetJS / xlsx — the grids' Excel export
  • mgrs and utm — the MGRS and UTM coordinate conversions
  • crypto-js — the optional passphrase encryption for backups and on-device storage
