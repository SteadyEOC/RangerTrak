  • Chrome's "Download" button is not installing: it saves a still copy of the page for reading ("Viewing an offline copy of this page"), in which the app doesn't work. Close it and install as above.

  • "RangerTrak is already open": only one copy of the app may edit your data at a time, so an older RangerTrak tab still open in the same browser brings this up. Switch to that one, or press Use this tab instead.

It asks the Board to say hello and names the most likely reason in one sentence. These are best guesses, because a browser can't see exactly why a connection failed. The usual ones: this device isn't on a network; it is on a different Wi-Fi from the Board laptop (check the Wi-Fi name in the Board laptop's window); the browser hasn't accepted the Board's certificate yet (press Open the Board, choose Advanced, then Proceed, and come back); the browser is blocking access to devices on this network (allow local network access for this site in the browser's site settings); or something answered that isn't a RangerTrak Board. Details holds the technical line for whoever is helping.
