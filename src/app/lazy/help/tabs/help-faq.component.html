Every Print button opens your browser's own print dialog, and the browser starts on the last place you printed to, which is often "Save as PDF". Choose your printer there once; the browser remembers it, so from then on it is Print, then Enter. If you only see a box asking for a file name, your browser saved the ICS-213 as a file instead: open that file and print it. In Chrome or Edge you can make it print directly by setting the browser to open PDFs rather than download them (Settings, Privacy and security, Site settings, PDF documents).
